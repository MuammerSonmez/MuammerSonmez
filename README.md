### 🏎️ RACLAB-ROVER: TEKNOFEST 2026 UGV
End-to-end ROS 2 autonomy stack for an unmanned ground vehicle: **dual-LiDAR fusion → RF2O odometry → MPPI controller → dynamic carrot goal generator**, plus a PID corridor follower, YOLOv8 sign detection and BehaviorTree orchestration, all in C++.

### ☕ Autonomous Service Robot with GUI & Auto-Docking
Graduation project: Kobuki-based café robot with SLAM, AMCL, Nav2 (A*/DWA), a customer ordering GUI with FIFO queue, and automatic docking. Tested on real hardware.

### 🚦 Multi-Robot Fleet Manager *(private, still ongoing)*
Master-slave fleet architecture on ROS 2 Humble with decision-support for optimal robot selection and a PyQt5 control GUI. Details coming soon. 🤫
